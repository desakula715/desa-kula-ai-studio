# Desa Kula AI Studio — V1

Fondasi aplikasi web untuk produksi konten storytelling Desa Kula.

## V1 saat ini
- Form topik
- Kategori konten
- Durasi minimal 10 menit
- Gaya narasi
- Content Plan
- Hook
- Pertanyaan utama
- Outline
- Storyboard per scene
- Paket judul/deskripsi/tag
- Tampilan responsif untuk desktop dan HP

## Menjalankan
Buka `index.html` langsung di browser.

## GitHub Pages
1. Buat repository baru, misalnya `desa-kula-ai-studio`.
2. Upload `index.html`, `style.css`, dan `app.js`.
3. Buka Settings → Pages.
4. Pilih branch utama dan folder `/root`.
5. Simpan. GitHub akan menerbitkan website.

## Tahap berikutnya
V2 akan mengganti generator lokal ini dengan backend AI:
- riset sumber
- penulisan naskah 10–30 menit
- storyboard berbasis naskah
- prompt visual
- voice-over
- subtitle
- video composer
- thumbnail
- paket YouTube

Jangan menaruh API key AI di JavaScript yang dipublikasikan melalui GitHub Pages.
